# Flipkart Web Scraping Using Python

## Project Overview
This project automates the extraction of mobile product information from Flipkart using Python and exports the collected data into a structured Excel file.

## Project Objectives
- Extract product information from multiple web pages.
- Handle missing data using conditional statements.
- Convert unstructured HTML data into structured tabular data.
- Export the extracted data into Excel.

## Data Extracted
- Product Name
- Product Price
- Product Description
- Customer Rating

## Technologies Used
- Python

- Visual Studio Code

## Project Features
- Multi-page web scraping
- HTML parsing

- HTTP status code monitoring
- Automated Excel file generation
